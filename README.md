# 网文下载器

AstrBot 网文下载插件。它使用 Legado/阅读书源搜索并下载小说，最后生成 TXT 文件。

这个插件适合在**私聊**里用。群聊中可能出现工具状态、选书确认和完成通知，容易刷屏。如果一定要在群里用，建议关闭 AstrBot 的 `provider_settings.show_tool_use_status`。

它也不适合拿来“随便搜搜”或找书推荐。最好先确定书名，遇到同名作品时再提供作者。

## 主要功能

- 导入 Legado/阅读书源和正文净化规则。
- 自动搜索多个书源并选择可用来源。
- 后台下载、断点续传并生成 TXT。
- 过滤广告、页脚和异常正文。
- 优先发送已有缓存，避免重复搜索和下载。
- 下载完成后主动通知。

## 怎么用

1. 在 AstrBot 中安装并启用插件。
2. 管理员导入书源，需要时再导入净化规则。
3. 直接和安装了本插件的 Bot 对话，例如：`下载《诡秘之主》，作者爱潜水的乌贼`。
4. 等待下载完成通知。只有想看进度时才问一次，不要反复轮询。

## 书源和净化规则

可以在 [AOAOSTAR 阅读APP源](https://legado.aoaostar.com/) 找书源和净化规则。内容由第三方维护，导入前请自行确认来源；部分规则可能不兼容本插件。

建议保留 **1000 到 3000 个书源**：

- 太少：小说覆盖不足，下载成功率低。
- 太多：搜索更慢，失效和超时书源也更多。

优先保留不需要登录、无需 WebView、健康度较好的静态书源。

## 注意

- 下载质量取决于书源和净化规则。
- 导入规则、刷新书源等管理操作建议只开放给管理员。
- 最终 TXT 会保存在插件数据目录，并作为共享缓存复用。
- 下载通知会额外调用一次 LLM；可将 `notify_mode` 改为 `direct` 或 `off`。

## LLM 工具

这些工具由 Bot 自动调用，普通用户不需要手动操作。

| 工具 | 权限 | 用途 |
| --- | --- | --- |
| `webnovel_search_books` | 普通用户 | 为已经确定的小说搜索下载来源。 |
| `webnovel_download_book` | 普通用户 | 下载搜索结果中的小说。 |
| `webnovel_download_status` | 普通用户 | 查看自己的下载任务。 |
| `webnovel_send_book` | 普通用户 | 发送已经下载好的小说缓存。 |
| `webnovel_import_sources` | 管理员 | 导入书源。 |
| `webnovel_list_sources` | 普通用户 | 查看书源和健康状态。 |
| `webnovel_refresh_sources` | 管理员 | 重新探测书源。 |
| `webnovel_probe_status` | 普通用户 | 查看探测进度。 |
| `webnovel_import_clean_rules` | 管理员 | 导入净化规则。 |
| `webnovel_list_clean_rules` | 普通用户 | 查看净化规则。 |

```text
发送缓存 -> 无缓存时搜索 -> 下载
```
