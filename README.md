# 网文下载器

这是一个面向 AstrBot 的小说下载插件，用来复用 Legado/阅读风格的开源书源，从书源中搜索小说、解析目录、抓取正文，并按章节顺序装订成 TXT 文件。

它不是内置固定站点爬虫，而是把“书源规则”当作抓取配置来执行。适合已经有阅读书源、希望在 AstrBot 里完成搜索、预检、下载、续传和 TXT 输出的场景。

## 主要能力

- 导入 Legado/阅读风格书源 JSON
- 按书名跨书源搜索候选小说
- 查看候选书源详情、健康状态和预检结果
- 根据书源规则抓取目录与章节正文
- 下载完成后自动装订 TXT
- 使用 `job.jsonl` 记录任务状态，支持失败后继续补抓和恢复装订
- 导入正文净化规则，下载时自动清理广告、页脚和杂质文本
- 后台探测书源搜索、预检和下载可用性

## 典型使用流程

1. 管理员导入书源。
2. 搜索小说名称，查看候选结果。
3. 选择标题、作者和来源都可信的候选。
4. 预检目录和正文抽样。
5. 启动下载任务。
6. 下载完成后生成 TXT。

插件会把下载任务和搜索缓存保存在 AstrBot 的插件数据目录中。下载任务不会只依赖内存状态，AstrBot 重启后仍可继续查看状态或恢复任务。

## 权限说明

以下操作会修改插件本地状态，或可能触发服务器访问外部 URL/本地路径，因此仅限 AstrBot 管理员使用：

- 导入书源
- 导入正文净化规则
- 刷新书源健康探测
- 删除已导入书源
- 抓取网页预览
- 使用手工正则方式创建下载任务
- 手动装订并可选清理 journal

普通用户可以使用查询、候选查看、下载状态查看，以及按已导入书源发起常规下载等能力。实际可用范围仍以 AstrBot 的权限系统和命令配置为准。

## 适合的书源

当前更适合以下类型：

- 静态 HTTP 页面
- 不依赖 WebView
- 不依赖登录态
- 不依赖复杂浏览器环境

对于需要登录、强浏览器渲染、复杂 JS 或反爬校验的书源，插件可能只能完成搜索，或在预检/下载阶段失败。

## 常用配置

- `book_sources`：启动时自动导入的书源列表。每项可以是 URL、文件路径或原始 JSON 文本。
- `clean_rule_sources`：启动时自动导入的正文净化规则列表。
- `auto_probe_on_import`：导入书源后是否自动加入后台健康探测队列。
- `max_workers`：正文下载并发数。
- `search_max_workers`：搜索阶段并发数。
- `probe_max_workers`：后台探测线程数。
- `request_timeout`：正文下载请求超时秒数。
- `search_request_timeout`：搜索请求超时秒数。
- `auto_assemble`：下载完成后是否自动生成 TXT。
- `cleanup_journal_after_assemble`：装订完成后是否删除 `job.jsonl`。默认建议保留，方便排查和恢复。
- `use_env_proxy`：是否使用 AstrBot 进程中的代理环境变量。
- `user_agent`：抓取目标站点时使用的 HTTP User-Agent。

## 注意事项

- 书源来自第三方时，请先查看规则内容和来源可信度。
- 不建议把导入、刷新、删除、网页预览等管理能力开放给非管理员。
- 下载失败时可以先查看书源详情、健康状态和任务最近错误，再决定是否换源。
- TXT 输出质量取决于书源规则、站点页面结构和净化规则。
